
# 电线选型计算器 v2.0

名称：电线选型计算器
描述：专为装修小白打造的家用电线选型计算器，支持普通回路与独立专线双轨计算，精准匹配各空间回路电线规格。

## 文件结构

```
docs/电线选型计算器/
├── wire_standards.json      # [静态] 国标电线规范 + 专线判定规则
├── preset_appliances.json   # [静态] 预置空间与家电模板（含专线标记）
└── 电线选型计算器_需求文档.md  # 本文档

js/
├── wire-calc-data.js        # 国标规范常量（WIRE_SPECS, DEDICATED_RULES, BREAKER_MAP）
├── wire-calc-presets.js     # 预置家电模板常量（PRESET_CATEGORIES, DEDICATED_PRESETS）
└── wire-calculator.js       # 计算器核心逻辑（WireCalculatorManager）
```

---

## 1. 产品概述

* **目标**：帮助用户通过勾选、修改家中电器，自动计算各空间回路所需电线规格（1.5/2.5/4/6㎡），支持普通回路与独立专线的双轨计算。
* **核心价值**：打破装修配线中"盲目加粗"误区，既防踩坑，又省预算。

## 4. 计算规则

### 4.1 普通回路推荐

**规则 1：插座保底**
* 非纯灯具回路（含任一功率 > 100W 的电器）→ 线径保底 2.5㎡
* 纯灯具回路（全部电器功率 ≤ 100W）→ 允许 1.5㎡

**规则 2：断路器容量 ≥ 总电流**
* 断路器选型：C10(10A) / C16(16A) / C20(20A) / C25(25A) / C32(32A) / C40(40A)
* 自动匹配第一个容量 ≥ 总电流的规格
* 保底线径断路器容量不足时，自动升级线径

**规则 3：漏保判定**
* 卫生间、厨房、阳台等涉水空间 → 强制提示配备漏电保护断路器 (RCBO)

### 4.2 专线回路推荐

**专线触发阈值**：功率 ≥ 2000W 自动建议转为专线

**专线计算**：
* 一对一计算：$I = P / 220$
* 专线最低线径：2.5㎡
* 根据电流匹配断路器 + 漏保判定

### 4.3 配电箱汇总

* 统计普通回路数 + 专线回路数 = 总回路数
* 计算全屋总功率、总电流
* 推荐入户总开关（C40/C50/C63）

## 5. UI 交互规范

### 5.1 空间卡片

* **电器列表**：最多展示 4 行，超出支持收起/展开
* **拖拽**：支持在不同空间卡片间拖拽电器
* **一键转专线**：功率 ≥ 2000W 的电器显示⚡按钮，点击移入专线列表
* **推荐结果**：固定在卡片底部，超出处局部滚动

### 5.2 独立专线面板

* 平铺列表展示所有专线回路
* 支持从预置列表快速添加
* 每行显示：设备名 | 所属空间 | 功率 | 电流 → 线径 + 断路器 | 漏保标记
* 支持编辑、删除、勾选/取消

### 5.3 配电箱汇总

* 6 宫格展示：普通回路数、专线回路数、总回路数、全屋总功率、全屋总电流、入户总开关
