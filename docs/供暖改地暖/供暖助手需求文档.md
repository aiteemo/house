# 供暖助手 需求文档

> 本文档是产品 + 交互 + 计算口径的完整规格。目标：把文档交给不了解本项目的人，也能按同样的用户体验和公式复刻出等价工具。实现以主站 `js/heating-assistant.js` + `js/heating-data.js` 为准；博客镜像须同步。

| 项 | 内容 |
|----|------|
| 名称 | 供暖助手 |
| 一句话 | 北京市市政集中供暖 vs 燃气壁挂炉自采暖的年度成本对比计算器 |
| 受众 | 北京（及同类政策）小区业主：纠结停供改地暖、选哪款壁挂炉、每年大概花多少 |
| 形态 | 静态页工具，无后端。参数实时演算，结果存本机 `localStorage` |
| 入口 | 主站装修助手工具箱；博客独立页 `blog/tools/heating/` |
| 版本口径 | v2：耗气 `V = Q / (H × η)`；气费北京居民阶梯；看板三档使用模式 |

## 〇、产品原则（复刻时必须保住）

1. **政策数据内置，用户不用自己查。** 集中供暖单价、停供基本热费比例、居民阶梯气价全部预填，并给出官方资料链接。
2. **贴近真实铺设，而不是拿房本面积一刀切。** 集中供暖按房本建筑面积计费；自采暖按实际地暖铺设面积算热负荷。
3. **难填的量产品化。** 生活用气、年度保养用「帮我算」问卷；机型用目录预设；使用模式用看板分段一点切换，而不是埋在表单下拉里来回翻。
4. **对比要能回答「换不换、何时回本」。** 回本 A（自采暖 vs 集中）+ 回本 B（对比炉 vs 当前炉）+ 累计支出趋势图，交汇点即回本。
5. **算得清楚、改得即时。** 无「计算」大按钮；公式核对可展开；看板随档位立即变数。
6. **默认对齐宣传口径，计价仍走真实阶梯。** 热指标 80 W/㎡、H=9.8 与商家耗气同构；气费绝不改用一口价 3.5 元/m³。

## 一、功能亮点（必须写进产品说明 / 复刻清单）

### 1. 主动采集北京市暖气与天然气价格

用户打开即可选官方档位，不必去发改委/街道查表。

**集中供暖（元/㎡·季）**，卡片展示「类型名 + 单价」：

| 用户类型 | 供暖类型 | 子类 | 单价 |
|----------|----------|------|------|
| 居民 | 市热力集团城市热网 | — | 24 |
| 居民 | 燃煤锅炉 | 直供 | 16.5 |
| 居民 | 燃煤锅炉 | 间供 | 19 |
| 居民 | 燃气、燃油、电锅炉 | — | 30 |
| 非居民 | 集中供热 | 城六区 | 45 |
| 非居民 | 集中供热 | 其他区域 | 43 |

**天然气居民阶梯（元/m³）**：≤1500 → 2.61；1500～2500 → 2.83；>2500 → 4.23。生活用气与采暖用气合计进阶梯，采暖归因用差额法（见公式）。

**停供基本热费**：默认按集中供暖全额 × **30%** 加到自采暖侧（政策常见口径，可关）。

数据来源见文末「引用资料」。卡片上同时展示单价，选中即高亮。

### 2. 以实际铺设面积对比，而不是一股脑用房本面积

| 面积 | 用途 | 交互 |
|------|------|------|
| 房本建筑面积 | **仅**集中供暖计费 | 数字框，默认 88.45 |
| 地暖实际铺设面积 | **仅**自采暖热负荷 Q | 数字框，默认 61；提示扣除柜体、厨卫等不铺区域 |

「同房本面积」勾选：铺设面积写入房本值并只读、样式加锁；改房本面积时铺设联动。取消勾选后恢复手填。不确定铺设面积的用户可勾选，知情用户可分开填——这是贴近真实环境的核心设计。

### 3. 供暖类型支持自定义价格

居民/非居民卡片之外，同一样式有「自定义价格」卡：内嵌数字框（元/㎡·季）。

- 点卡片或点输入框即切到自定义；选官方卡时清空自定义价。
- 卡片下方「本采暖季费用」条：`面积 × 单价`，就近反馈，不强迫用户滚到结果区。

### 4. 预设常见机型，同时支持自定义与本机校正

- 机型目录独立 JSON（约 20 款 24kW 档：力科、菲斯曼、威能、林内、博世、小松鼠、海尔、美的、小沃、阿里斯顿、万家乐、万和等），含冷凝/常规、室外补偿、η、功率、参考价、年限、维保、备注。
- 下拉选中即填充全部参数。第一项「自定义参数」不覆盖当前手填。
- **对比机型**非必选：不选则只与集中供暖比；选目录或「自定义对比参数」则展开对比炉全套字段。
- **本机校正覆盖**：选手型后改价/η/冷凝等，按 `model_name` 记入 `boiler_overrides`。再选同一机型会「目录默认 + 覆盖」，不写回公共 JSON。hint 显示「当前机型已校正」。永久改全站默认：改 JSON 再发布。
- 「重置参数」：确认后清空全部 override 与表单，回到目录/内置默认（不影响线上 JSON）。

### 5. 把「没概念」的量做成问卷式输入

普通人很难随口报「一年生活用气多少方」「保养一年多少钱」。做成弹窗选择题，确认回填，仍可手改。

**全年生活用气「帮我算」**

- 入口：输入框旁链接按钮，不打断主流程。
- 基准：2 人、1 卫、正常做饭、无零冷水、几乎不用浴缸 → **220 m³/年**（不含采暖）。
- 五维点选（每维单选 Chip，点即切，无下拉）：

| 维度 | 选项（系数） |
|------|----------------|
| 家庭人数 | 1人 0.70 / **2人 1.00** / 3人 1.25 / 4人及以上 1.50 |
| 做饭频率 | 几乎不开火 0.75 / **正常日常做饭 1.00** |
| 卫生间数量 | **1个 1.00** / 2个及以上 1.15 |
| 浴缸 | **几乎不用 1.00** / 偶尔 1.15 / 经常 1.30 |
| 零冷水 | **无 1.00** / 点动按需 1.15 / 定时循环 1.30 |

- `估算 = ceil(220 × 各系数连乘)`，弹窗内实时显示；「确认并填入」写回全年生活用气。
- 生活用气**默认不进供暖对比金额**，但参与阶梯，会抬高采暖用气单价。

**年度保养「帮我算」**

- 打开时按当前「是否冷凝」预选设备类型；产地默认国产。
- 常规炉：2 年 1 保，年均 = 单次价 ÷ 2；冷凝炉：1 年 1 保，年均 = 单次价。
- 单次基准：进口常规 500 / 国产常规 420 / 进口冷凝 650 / 国产冷凝 480。
- 弹窗展示「单次 ÷ 周期 = 年均」，确认回填。

### 6. 机型对比 + 双回本 + 趋势图交汇

用户改自采暖时通常要在几款炉之间选。工具同时算三条线：

| 回本 | 含义 | 公式 | 何时显示 |
|------|------|------|----------|
| **回本 A** | 当前自采暖 vs 集中供暖 | 仅当自采暖更省：`购炉价 ÷ (集中年费 − 自采暖对比年费)` | 始终尝试；更贵则「不适用」 |
| **回本 B** | 对比炉 vs 当前炉 | 仅当有节气费且有增量投资：`ΔP ÷ ΔC` | 选了对比机型 |

ΔV、ΔC 按两边 η 演算耗气，再走阶梯差额，不是宣传一口价。ΔP≤0 且有节气 → 「即时（无增量投资）」；无节气 → 「不适用」。回本 B ≤ 对比炉质保年限则提示「推荐更换」。

**累计总支出趋势图（ECharts 折线，仅左栏结果区，不进看板/抽屉）**

- 未选对比炉：蓝=集中（每年累加全额）、黄=当前自采暖（第 0 年含购炉，之后每年气费+维保+可选停供）。
- 已选对比炉：蓝=集中；黄=当前炉；绿=对比炉。黄/绿交汇年 ≈ 回本 B；绿线上可打虚线标记。
- 横轴年限：有正回本 B 时 `ceil(回本)+1`，否则对比炉质保+1 或当前炉年限+1，夹在 2～40。
- 图上三张摘要卡：N 年集中总成本、N 年方案总成本、回本 A 或 B。
- 维保与停供两边相同，**不影响黄绿交汇**（交汇只反映气费差摊增量购机）。

**换机省气摘要**（仅左栏回本 B 下方，仅 `payback > 0`，**不进看板**）：年省气 ΔV、年省气费 ΔC；5 年共省；N 年共省（N=质保，与 5 年差 <0.1 则合并不重复）；回本年 X 共省仅当与 N、5 均差 ≥0.1；X>N 加「超出计划使用/质保年限」；标题写明「未扣购机差」；小字：北京阶梯，非 3.5 元/m³。

### 7. 计算过程可核对 + 供暖小知识

左栏「核心公式与计算过程」默认折叠，展开后按 ①～⑧ 逐步代入当前数字（改表单实时刷新）：集中费用 → Q/V → 日均 → 阶梯差额 → 折旧维保 → 口径费用 → 回本 A →（可选）回本 B。每步左侧公式、右侧代入。

供暖小知识默认折叠四张卡：供暖季 11/15–3/15（120 天）；停供须提前 30 日、缴约 30% 基本热费；室温标准（居室/卫 ≥18℃、厨 ≥14℃）；冷凝炉宣传口径效率与价差。引用资料外链同样默认折叠。免责：理论区间，未纳入保温、门窗、楼层等。

### 8. 结果看板调档位，感知花费上下限

宽屏右侧粘滞看板、窄屏底部抽屉，是**对照实验台**，不是只读摘要。

**使用模式（看板顶部三段，一点即切，禁止表单下拉）**

| 档 | 系数 | 含义 |
|----|------|------|
| 舒适 | 1.0 | 24h 恒温高舒适（花费上限方向） |
| 正常 | 0.7 | 白天降温/下班恢复（默认） |
| 节能 | 0.5 | 低温保温/局部关回路（花费下限方向） |

系数乘在 **Q** 上。切换立即刷新看板数字、结构条、回本、左栏结果与趋势图。旁注当前 `×系数 · 说明`。表单只留一句提示「请在右侧看板切换」。

**对比口径分段（短文案 + title + 下方 hint）**

- 「纯供暖对比」（默认）：刨除生活用气金额，只比供暖本身。
- 「家庭总燃气」：自采暖含全年气费，集中仍只有供暖费，适合看总账、不宜直接比优劣。

看板按钮禁止折行（`nowrap`），避免窄侧栏把「供暖对比（刨除生活用气）」撑破。完整解释在 hint。

**停供开关**默认开：hint 写出「约 30%（¥xxx）已加到自采暖侧」。关则与旧版一致（气+设备 vs 集中全额）。

看板还展示：集中 vs 自采暖两 KPI、更贵/更省差额与相对集中的%、费用结构条（气费 / 停供 / 设备·维保）及图例金额、回本 A。**省气摘要不进看板。**

窄屏 Peek：`[仅采暖]` / `[含生活用气]` + 省/多花金额；回本适用且文案不挤时附短数字。点开半屏：两行年费 + 使用模式 + 口径 + 停供。趋势图与公式不进抽屉。

## 五、模块规格

### 5.1 房屋信息

见亮点 2。`inputmode="decimal"`；桌面数字框约 180px 宽。

### 5.2 市政集中供暖

见亮点 1、3。选项 key = `supply_type__` + `supply_sub_type`。费用 = 房本面积 × 单价。

### 5.3 自采暖机型与 η

**η**：Chip 预设 90 / 92 / 94 / 98 / 104 / 106 / 108% + 数字框（填 108 = 108%，范围约 80–110）。Chip/手改 → `is_eta_customized=true`。

**冷凝 / 室外**：仅当未手改 η 时改写建议值：非冷凝 90%，冷凝 108%；有室外补偿再 **+2 个百分点**。不乘 0.7 / 0.9。功率在高级折叠，**不参与耗气**。

**高级**：热指标 W/㎡、H kWh/m³（hint：默认宣传同构；可改低位如 8.9）。

**目录载入**：写入目录 η，`is_eta_customized=false`。`loadState` 缺 η / 热指标 / H 必须 fallback，禁止 NaN。

**对比炉字段**：η、冷凝、室外、采购价、年限、维保；功率折叠。相对节能率 = `(V0−V1)/V0`，不是输入项。

手改当前炉或对比炉参数时调用 `rememberBoilerOverride`（须已有 model 名）。选机型走 `boilerFromCatalogWithOverride`。

### 5.4 使用模式

见亮点 8。禁止下拉。看板与抽屉各渲染一套分段，点击写入 `user_coeff` 并立即 `refreshResult`。

### 5.5 计算公式（复刻必须一致）

```
heat_load_kW_m2 = 80/1000 = 0.08     # 高级可改
H = 9.8                               # kWh/m³，高级可改
Q_season = 铺设面积 × heat_load × 24 × 120 × user_coeff
V_season = Q_season / (H × η)         # η 小数，如 1.08
total_gas = V_season + year_life_gas

gas_cost      = ladder(total_gas)
life_gas_cost = ladder(year_life_gas)
heating_gas_cost = gas_cost − life_gas_cost

year_depreciation = 采购价 / 计划使用年限
year_fixed = year_depreciation + 年度保养

heating_compare_cost = heating_gas_cost + year_fixed
household_total_cost = gas_cost + year_fixed

pause_basic_fee = 计入停供 ? 集中费用 × 0.3 : 0
self_total = 当前口径基础 + pause_basic_fee
diff = self_total − 集中费用          # >0 自采暖更贵
annual_saving = 集中费用 − self_total
payback_A = annual_saving > 0 ? 采购价 / annual_saving : 不适用
```

阶梯累进：从低档吃满再进下一档。`user_coeff` 只乘 Q。

**热力学口径**：H=9.8 × 铭牌 η（可 >100%）与商家耗气同构——9.8 是宣传高位折算，108% 是市场常见 LHV 标称，连乘不是严格 HHV 物理极限。气费仍用阶梯。已废弃：冷凝×0.7、室外×0.9、功率分档叠乘。

**回本 B**

```
V0, V1 = 当前炉 / 对比炉采暖季耗气
ΔC = ladder(生活+V0).cost − ladder(生活+V1).cost
ΔP = 对比炉价 − 当前炉价
payback_B = (ΔC>0 且 ΔP>0) ? ΔP/ΔC : (ΔC>0 且 ΔP≤0 ? 0 : 不适用)
N 年净收益 = ΔC×N − ΔP   # N=对比炉质保/计划使用
```

### 5.6 方案对比结果（左栏）

- 三卡：集中年费、自采暖年费（堆叠显示气费 + 停供 + 设备/维保）、年度差额（绿省/红贵）。
- 回本芯片：A；有对比炉则 B + N 年净收益；未启用 B 显示「选对比机型后计算」。
- 其后：省气摘要、趋势图、公式核对、明细（η、Q、V、阶梯、气费、折旧、维保、停供、使用模式系数等）。

### 5.7 实时演算与刷新

| 操作 | 刷新 |
|------|------|
| 数字 `input` | 100ms 防抖 |
| 机型/对比机型、冷凝室外、η Chip、供暖卡、同房本、口径、停供、使用模式 | 立即 |
| 看板/抽屉控件 | `refreshResult`：重绘画板、Peek、结果区、趋势图，不整页重绘表单 |

### 5.8 弹窗层级

用气/保养弹窗与「工具提示词」浮钮 **高于** 抽屉。抽屉展开：`html, body` overflow hidden；抽屉内可滚。有 `visualViewport` 时底栏避开键盘；否则 `safe-area-inset-bottom`。
