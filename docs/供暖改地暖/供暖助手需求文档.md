## 一、功能模块

### 模块1：房屋信息
| 参数 | 类型 | 说明 |
|------|------|------|
| 房本建筑面积 | 数字输入 | 集中供暖唯一计费面积 |
| 地暖实际铺设面积 | 数字输入 | 自采暖专用，扣除柜体、厨卫不铺区域 |

### 模块2：市政集中供暖
- 支持居民/非居民用户类型选择
- 支持自定义价格输入（同卡片样式）
- 实时计算：本采暖季费用 = 建筑面积 × 单价

### 模块3：燃气壁挂炉自采暖

#### 3.1 机型参数
| 参数 | 说明 |
|------|------|
| 机型快捷选择 | 下拉框，选中自动填充全部参数（力科S4 / 菲斯曼B1JG） |
| 是否全预混冷凝炉 | 单选：是/否（冷凝炉修正系数0.7） |
| 最小输出功率 | 数字输入（影响功率适配修正系数） |
| 是否带室外温度补偿 | 单选：是/否（补偿修正系数0.9） |
| 壁挂炉采购总价 | 数字输入（计算设备折旧） |
| 计划使用/质保年限 | 数字输入（计算年均折旧） |
| 年度保养费用 | 数字输入 |

#### 3.2 使用行为
| 参数 | 说明 |
|------|------|
| 使用模式 | 下拉选择：24小时恒温(1.0) / 离家低温节能(0.7) |
| 全年生活用气 | 数字输入，支持「帮我算」辅助估算 |

#### 3.3 计算公式
```
daily_base_kwh = 铺设面积 × 0.1 × 24
daily_base_gas = daily_base_kwh / 10
daily_real_gas = daily_base_gas × condenser_coeff × temp_comp_coeff × power_coeff × user_coeff
season_gas = daily_real_gas × 120
total_gas = season_gas + year_life_gas

# 阶梯气价（生活用气参与梯度）
gas_cost      = ladder(total_gas)          # 全年总燃气费
life_gas_cost = ladder(year_life_gas)      # 仅生活用气费用
heating_gas_cost = gas_cost − life_gas_cost  # 采暖归因气费（差额法）

heating_compare_cost   = heating_gas_cost + 折旧 + 维保   # 供暖对比口径（默认）
household_total_cost   = gas_cost + 折旧 + 维保           # 家庭燃气总账
```

#### 3.4 修正系数
| 系数 | 条件 | 值 |
|------|------|-----|
| 冷凝炉 | 是 | 0.7 |
| 冷凝炉 | 否 | 1.0 |
| 室外温度补偿 | 是 | 0.9 |
| 室外温度补偿 | 否 | 1.0 |
| 功率适配 | 最小功率 ≤ 3.1kW | 0.95 |
| 功率适配 | 最小功率 ≤ 3.8kW | 1.0 |
| 功率适配 | 最小功率 > 3.8kW | 1.05 |

### 模块4：北京阶梯燃气累进计价
| 档位 | 范围 | 单价 |
|------|------|------|
| 第一档 | 0～1500m³ | 2.61 元/m³ |
| 第二档 | 1500～2500m³ | 2.83 元/m³ |
| 第三档 | >2500m³ | 4.23 元/m³ |

### 模块5：方案对比结果
双口径切换（默认「供暖对比」）：
1. **供暖对比（刨除生活用气）**：`heating_compare_cost` vs 集中供暖费。生活用气只抬高阶梯单价，本身不进对比。
2. **家庭燃气总账**：`household_total_cost` vs 集中供暖费。含生活用气，适合看全年气费总账，不宜直接比优劣。

展示内容：
- 集中供暖年度费用 vs 自采暖对应口径费用
- 年度差额（正/负）
- 静态回本年限（自采暖更贵时显示）
- 自采暖明细：耗气量、阶梯、气价、生活用气费用、采暖归因气费、全年总燃气费、折旧、维保
- 修正系数明细
### 模块6：生活用气「帮我算」
- 弹窗式交互，5个维度选项
- 公式：base_value(220) × 人数系数 × 做饭系数 × 卫数系数 × 浴缸系数 × 零冷水系数
- 结果向上取整，确认后回填输入框

## 二、UI 布局

### 侧边导航
- 固定在页面左侧，垂直居中
- 5个锚点：房屋信息 / 集中供暖 / 燃气自采暖 / 对比结果 / 引用资料
- 滚动自动高亮当前板块

### 板块结构
1. 房屋信息（建筑面积 + 铺设面积）
2. 市政集中供暖（类型选择 + 自定义价格 + 费用结果）
3. 燃气壁挂炉自采暖（机型 + 参数 + 使用行为 + 计算按钮）
4. 对比结果（三栏对比 + 明细表）
5. 供暖小知识
6. 引用资料
7. 免责声明
