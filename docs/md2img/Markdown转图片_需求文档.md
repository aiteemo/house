# Markdown 转图片工具 v1.0

名称：Markdown 转图片  
描述：将 Markdown 渲染为精美卡片预览，一键下载 PNG，适合生活分享、工作汇报、科普说明。

## 文件结构

```
docs/md2img/
└── Markdown转图片_需求文档.md   # 本需求文档

js/
├── md2img-themes.js             # 主题预设与默认样例
└── md2img.js                    # Md2ImgManager 核心逻辑

css/style.css                    # .md2img-* 样式
index.html                       # 引入脚本
js/style-quiz.js                 # 工具箱入口卡片
```

依赖（CDN，首次打开工具时按需加载）：
- marked（Markdown → HTML，GFM）
- highlight.js（代码高亮）
- mermaid（流程图）
- html-to-image（DOM → PNG）

## 一、功能模块

### 模块1：Markdown 编辑
| 能力 | 说明 |
|------|------|
| 文本输入 | 左侧多行编辑区，实时预览 |
| 默认样例 | 首次进入填充含标题/表格/代码/流程图的示例 |
| 持久化 | `localStorage` 保存正文、主题、宽度 |

### 模块2：语法支持（v1）
| 类型 | 支持 |
|------|------|
| 基础 | 标题 H1–H3、段落、加粗/斜体、引用、有序/无序列表、分割线、链接 |
| 表格 | GFM 表格 |
| 代码 | 行内代码、围栏代码块 + highlight.js 高亮 |
| 图片 | `![alt](url)`；外链需可跨域，否则导出可能空白 |
| 流程图 | ` ```mermaid ` 代码块 |

暂不支持（二期）：数学公式、任务列表勾选交互、自定义 CSS 编辑器、PDF。

### 模块3：预览卡片
| 参数 | 说明 |
|------|------|
| 设计宽度 | 固定档：390（手机）/ 750（朋友圈）/ 1080（高清） |
| 高度 | 按内容自适应，不固定画布高度 |
| 缩放显示 | 预览区用 `transform: scale` 适配窄屏，导出仍用设计宽度 |
| 主题 | `data-theme` + CSS 变量驱动 |

### 模块4：风格预设（4 套）
| id | 名称 | 场景 |
|----|------|------|
| `life` | 生活分享 | 温暖纸感、圆润卡片，适合日常/宠物/家居分享 |
| `work` | 工作简报 | 白底深字、蓝色强调，适合会议纪要/清单 |
| `science` | 科普说明 | 浅青灰底、清晰层级，适合知识卡片 |
| `code` | 深色代码 | 深底浅字，适合技术笔记/代码片段 |

### 模块5：导出
| 能力 | 说明 |
|------|------|
| 下载 PNG | 点击下载；文件名 `md2img_主题_时间戳.png` |
| 导出前 | `document.fonts.ready` + mermaid 渲染完成后再截图 |
| 像素比 | `pixelRatio: 2`，保证清晰度 |
| 长图 | v1 不做分页；超高内容依赖浏览器能力，失败时 toast 提示 |

## 二、UI 布局

```
返回工具箱
┌ 标题 / 说明 ─────────────────────────────┐
│ 风格卡片 ×4     宽度档位 ×3     [下载PNG] │
├──────────────┬──────────────────────────┤
│ Markdown     │ 预览视口（缩放）           │
│ 编辑区       │ ┌ 卡片(设计宽×自适应高) ┐ │
│              │ └─────────────────────┘ │
└──────────────┴──────────────────────────┘
```

- 桌面：左右分栏
- 窄屏：上下堆叠（编辑在上，预览在下）

## 三、技术要点

1. **按需加载 CDN**：进入工具再注入 script/link，避免拖慢主站。
2. **Mermaid**：marked 渲染后将 `.language-mermaid` 转为 `.mermaid`，再 `mermaid.run()`。
3. **截图节点**：只截 `#md2imgCapture`（真实设计宽度），不截缩放外壳。
4. **外链图**：导出前尽量 `crossOrigin=anonymous`；失败不阻塞整图。
5. **接入方式**：与供暖助手一致，挂在「小工具」工具箱。
