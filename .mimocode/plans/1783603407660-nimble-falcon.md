# 装修风格助手 — 全选功能 + 答题状态持久化

## 背景

"装修风格助手"（Style Quiz）当前是单选题模式，答案仅存于内存，刷新即丢失。用户希望：
1. **部分题目支持"全选"** — 一键选中/取消所有选项（多选模式）
2. **答题状态持久化** — localStorage 保存答案，刷新页面后可继续答题

## 涉及文件

| 文件 | 改动 |
|------|------|
| `js/style-quiz-data.js` | 给需要多选的问题加 `multiSelect: true` 字段 |
| `js/style-quiz.js` | 答题逻辑改造：多选支持、全选按钮、localStorage 持久化 |
| `css/style.css` | 全选按钮样式、多选 checkbox 样式 |

## 一、数据层改造 (`style-quiz-data.js`)

仅 **q7（生活方式）** 加 `multiSelect: true` — 人可以同时喜欢做饭+阅读+看电影，天然多选。其他问题保持单选。

```js
{
    id: 'q7',
    title: '你的生活方式？',
    multiSelect: true,   // ← 新增
    ...
}
```

## 二、答题逻辑改造 (`style-quiz.js`)

### 2.1 数据模型变更

- `this.answers[qId]`：单选时存 `optionId`（string），多选时存 `optionId[]`（数组）
- 新增 `this.currentQuestion = 0` 保持不变
- 新增 `saveState()` / `loadState()` 方法

### 2.2 renderQuiz() 改造

- 多选题目：选项用 checkbox 样式（方框 ✓），单选用 radio 样式（圆点）
- 多选题目标题旁显示"全选"按钮
- 点击选项时：单选直接替换；多选 toggle 数组中的对应项
- "全选"按钮：点击时 toggle — 如果已全选则全部取消，否则全部选中

### 2.3 calculateResult() 改造

多选时，遍历用户选中的每个选项，分别累加 bonus/penalty/blacklist。逻辑不变，只是 `selectedId` 变为数组循环。

### 2.4 持久化

```js
saveState() {
    const data = {
        currentQuestion: this.currentQuestion,
        answers: this.answers,
        state: this.state
    };
    localStorage.setItem('style_quiz_state', JSON.stringify(data));
}

loadState() {
    const raw = localStorage.getItem('style_quiz_state');
    if (!raw) return false;
    try {
        const data = JSON.parse(raw);
        this.currentQuestion = data.currentQuestion || 0;
        this.answers = data.answers || {};
        this.state = data.state || 'intro';
        return true;
    } catch { return false; }
}
```

- constructor 中调用 `loadState()`，如果有效则恢复状态
- 每次切换选项、切换题目、提交答案后调用 `saveState()`
- "重新测试"时清除 localStorage
- 返回工具箱时保存当前状态（不重置）

### 2.5 "下一题"按钮逻辑

- 单选题：必须选一个才能下一步（当前逻辑不变）
- 多选题：允许不选直接跳过（0 个选项也算有效状态），按钮始终可点击

## 三、CSS 样式 (`css/style.css`)

新增样式：
- `.quiz-select-all` — 全选按钮（小巧的文字按钮，放在题目标题右侧）
- `.quiz-option.multi` — 多选选项容器（方框 checkbox 替代圆点 radio）
- `.quiz-option.multi .quiz-option-radio` — 方框样式

## 四、验证方式

1. 打开页面 → 小工具 → 装修风格助手 → 开始测试
2. 前6题为单选，行为不变
3. 第7题（生活方式）出现"全选"按钮，可多选；第8题仍为单选
4. 点击"全选" → 所有选项被选中；再次点击 → 全部取消
5. 答完题查看结果 → 分数正确（多选的 bonus/penalty 都累加）
6. 刷新页面 → 状态恢复到上次答题的位置
7. "重新测试" → 清除 localStorage，回到介绍页
